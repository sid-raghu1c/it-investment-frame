Accessibility & Screen Reader Information

The modernized MPSeDC portal has been designed to strictly comply with World Wide Web Consortium (W3C) Web Content Accessibility Guidelines (WCAG) 2.1 Level AA and the Guidelines for Indian Government Websites (GIGW 3.0).

Compatible Screen Readers:

  • NonVisual Desktop Access (NVDA) - Free & Open Source for Windows
  • Job Access With Speech (JAWS) - Windows
  • VoiceOver - Built into macOS and iOS devices
  • TalkBack - Android accessibility service

Accessibility Keyboard Shortcuts:

  • Ctrl + K: Instant Global Smart Search
  • Tab / Shift + Tab: Navigate focus sequentially
  • Enter: Activate buttons, expand accordions, and follow links
  • Esc: Dismiss any open modal overlay
